01. What is Python?

Python ek programming language hai. Iska use websites, automation, data analysis, AI aur machine learning mein hota hai.

02. Your first Python program

print() ka use screen par output show karne ke liye hota hai.

print("Hello, World!")
print("I am learning Python")

Expected output:

Hello, World!
I am learning Python
Remember: text ko quotes ke andar likhte hain. Python mein spelling aur brackets sahi hona zaroori hai.

03. Variables

Variable ek naam hai jiske through hum value ko store aur use kar sakte hain. 

name = "Sudhanshu"
age = 20

print(name)
print(age)

Expected output:

Sudhanshu
20

Yahan name mein text aur age mein number store kiya gaya hai.

04. Basic data types

name = "Alex"       # String: text
age = 18            # Integer: whole number
price = 99.5        # Float: decimal number
is_student = True   # Boolean: True or False

print(type(name))
print(type(age))
print(type(price))
print(type(is_student))

Common data types: str, int, float aur bool.

05. Basic calculations

a = 10
b = 3

print(a + b)  # Addition
print(a - b)  # Subtraction
print(a * b)  # Multiplication
print(a / b)  # Division

Expected output:

13
7
30
3.3333333333333335

Quick Practice

Agar code hai x = 5 aur y = 4, toh print(x * y) ka output kya hoga?
