03 — Learning roadmap

Build strong foundations, then go deeper.

These are learning stages and goals, not claims that every skill is already mastered.

Stage 01 · Current foundations

HTML, CSS, Python, Git and core mathematics

Practice semantic pages, responsive layouts, loops, functions, basic algorithms and version control.

Stage 02 · Next

JavaScript, DOM, APIs and SQL

Make pages interactive, validate forms, fetch public API data and store structured information.

Stage 03 · Build full-stack

React, backend, databases and testing

Create complete applications with accessible interfaces, reliable data handling and clear documentation.

Stage 04 · AI direction

Linear algebra, statistics, machine learning and AI APIs

Learn the maths, evaluate models carefully and build useful AI features with responsible data handling.

Stage 05 · Deployment

Linux, networking, cloud, security and MLOps

Learn deployment, monitoring, testing and security fundamentals before scaling projects.
