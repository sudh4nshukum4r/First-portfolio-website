## Supported Versions

The latest version of LE4RNSP4CE is the primary version maintained for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in LE4RNSP4CE, please report it privately to the repository owner through GitHub.

Please do not publish sensitive information, passwords, authentication tokens, private user data, or exploitable vulnerabilities in public issues.

## Security Measures

- Firebase Authentication is used for user authentication.
- Firebase Security Rules are used to control access to database data.
- API keys should have appropriate application and API restrictions where supported.
- Credentials, passwords, private keys, and service account files must not be committed to the repository.
- Security settings and access rules should be reviewed regularly.

## Responsible Disclosure

Please allow the repository owner reasonable time to investigate and address a reported vulnerability before publicly disclosing it.
